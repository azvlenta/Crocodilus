# 🐊 Crocodilus

Crocodilus is a simple, fast, and elegant task management application inspired by bullet journaling and the aesthetics of a crocodile.

The app allows users to create custom tasks, mark them as completed, and delete them through a clean, responsive interface designed for both desktop and mobile devices.

## ✨ Features

- ✅ Create tasks
- 📝 Add task descriptions
- 🎨 Choose custom colors
- 📅 Automatic creation date tracking
- ✔️ Mark tasks as completed
- 🗑️ Delete tasks
- 💾 Automatic local storage saving
- 📱 Mobile-friendly interface
- 🚀 Installable as a Progressive Web App (PWA)

## 📱 Android Installation

1. Open the application in Chrome.
2. Tap the menu button (⋮).
3. Select **"Install app"** or **"Add to Home Screen"**.
4. Enjoy Crocodilus as a standalone application.
